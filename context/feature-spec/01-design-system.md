Read `Agents.md before starting.

We're adding the design system and UI primitive components. 

Install and configure `shadcn/ui`.

Add these shadcn/ui components:
- Button
- card
- dialog
- input
- badge
- alert
- tooltip
- dropdown-menu
- tabs
- accordion
- textarea
- scroll-area
- select
- checkbox
- radio-group

Do not modify the generated `components/ui/*` files after installation. 

Also install `lucide-react` for icons.

Ensure all components match the existing dark theme in `globals.css`.

### Check when done 
- [x] shadcn/ui components installed
- [x] lucide-react installed
- [x] components match dark theme
- [x] no modifications to generated `components/ui/*` files
- [x] 'cn()' function works correctly
- [x] no default light styling applied
